Which dithering method should you choose?

MethodVisual characterGood use cases
ThresholdHard black-and-white separation with no simulated intermediate tones.Logos, silhouettes, stencils, and bold poster graphics.
Bayer 8×8Regular, repeating ordered pattern that remains stable from frame to frame.Retro UI, pixel-art textures, print-like patterns, and animation.
StuckiError diffusion distributes quantization error to nearby cells for smoother tonal detail.Portraits, photographs, gradients, and detailed monochrome artwork.

Get cleaner 1-bit results

  • Start with contrast: Separate the subject from the background before changing the threshold.
  • Choose grid density intentionally: A coarse grid creates bold pixel blocks; a fine grid preserves detail but increases output complexity.
  • Use Bayer for temporal stability: Its fixed matrix can look less noisy across video frames than error diffusion.
  • Use Stucki Factor carefully: Higher diffusion strength can reveal gradients but may also create busy texture.

1-bit dither FAQ

Is dithering the same as grayscale?

No. A 1-bit result uses only two output states. Dithering arranges those states spatially to suggest intermediate tones.

Can I use colors other than black and white?

Yes. Set the background and unit colors, sample the original image colors, or choose one of the volumetric color mappings.

Does SVG remain editable?

Dither SVG uses vector rectangles or circles, so compatible design tools can edit the individual elements after export.
